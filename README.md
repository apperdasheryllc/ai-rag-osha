# AI RAG OSHA Demo - Apperdashery

This repository showcases IT skills and modern technologies used in enterprise software development:
- **AI Engineering**: Anthropic, Retrieval Augmented Generation (RAG), ChromaDB, LiteLLM, Vector Databases
- **Backend**: Python, FastAPI
- **Mobile Development**: iOS, Swift, SwiftUI

## ai-rag-pipeline
A demonstration Retrieval-Augmented Generation (RAG) pipeline for OSHA safety regulations. This example ai-rag-pipeline scrapes OSHA regulatory text from the web, processes it into chunks, generates embeddings, and provides semantic search capabilities.

## ai-rag-api
A web API that uses Anthropic Claude + Chroma RAG for OSHA PPE standards.
